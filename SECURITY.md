# Security Policy

## Supported versions

Security fixes are currently focused on the latest development version of Dayflow.

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability.

Instead, contact the project maintainer privately through the security contact configured for the GitHub repository. Include:

- a clear description of the issue
- reproduction steps
- affected version/commit
- relevant logs or screenshots
- any suggested mitigation

Dayflow is designed as a local-first application. A security report involving local data, file access, notifications, or the Tauri native bridge is especially useful when it includes the affected operating-system version and reproduction details.
